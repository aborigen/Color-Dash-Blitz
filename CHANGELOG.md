# Changelog

All notable changes to the Color Dash Blitz project will be documented in this file.

## [0.7.0] - 2024-06-09

### Changed
- **Resource Sanitization**: Removed all external resource dependencies (Google Fonts, remote image patterns) to ensure the game is fully standalone and offline-capable.
- **Typography**: Updated Tailwind config to use a robust system font stack for improved performance and privacy.

## [0.6.7] - 2024-06-08

### Changed
- **Grid Refactoring**: Optimized the 4-color grid difficulty level to use a 1x4 horizontal layout instead of 2x2. This significantly reduces vertical space usage in portrait mode and prevents UI element overlapping on smaller screens.
