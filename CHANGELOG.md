
# Changelog

All notable changes to the Color Dash Blitz project will be documented in this file.

## [0.9.0] - 2024-06-12

### Added
- **Multi-Platform Build Scripts**: Implemented `build:sber`, `build:vk`, and `build:yandex` commands for automated packaging.
- **Publishing Guide**: Added `PUBLISHING_GUIDE.md` with technical instructions for store submissions.
- **Optimized Archiving**: Updated `archive.sh` to produce flat-structured ZIP files required by game portals.

## [0.8.0] - 2024-06-11

### Changed
- **Landscape Optimization**: Refactored `GameContainer` to use a side-by-side layout in landscape orientation.
- **Orientation Responsiveness**: Adjusted scaling of target indicators and choice grids for short-height viewports.
