# Changelog

All notable changes to the Color Dash Blitz project will be documented in this file.

## [0.8.0] - 2024-06-11

### Changed
- **Landscape Optimization**: Refactored `GameContainer` to use a side-by-side layout in landscape orientation, maximizing horizontal space and improving thumb ergonomics.
- **Orientation Responsiveness**: Adjusted scaling of target indicators and choice grids specifically for short-height viewports.
- **HUD Polish**: Minimized HUD vertical footprint in landscape mode to prevent gameplay area compression.

## [0.7.5] - 2024-06-10

### Changed
- **UI Responsiveness**: Refined vertical spacing and component scaling for improved playability on small mobile devices (e.g., iPhone SE).
- **Target Indicator**: Optimized sizing of the target color hub to prevent overlap on compact screens.
- **HUD Polish**: Reduced padding and adjusted element sizing in the Blitz Bar and score indicator for mobile viewports.
